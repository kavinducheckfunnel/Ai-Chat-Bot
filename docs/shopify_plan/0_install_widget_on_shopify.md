Good question. The Shopify equivalent is actually simpler than WordPress — Shopify themes accept raw HTML/JS, and our existing snippet works as-is. There are three paths depending on how non-technical the merchant is:

## 🛍️ Three ways to install the widget on Shopify

### Option A — `theme.liquid` edit (recommended for the merchant themselves)

This is the Shopify equivalent of editing `functions.php` in WordPress. No app needed, no extra cost, works on every plan.

```
Shopify Admin → Online Store → Themes → (your active theme)
  → Actions → Edit code
  → Layout/theme.liquid
  → Find the closing </body> tag near the bottom
  → Paste the snippet from /portal/settings → Channels & embed RIGHT BEFORE </body>
  → Save
```

The snippet generated by `embedCodeGenerator.js` is plain HTML + CSS + JS — Liquid only processes `{% %}` and `{{ }}` template tags, so raw `<style>`, `<script>`, `<div>` pass through untouched. **Same snippet, no special "Shopify format" needed.**

### Option B — No-code custom-code app (Shopify's WPCode equivalent)

For merchants who don't want to touch theme code, the Shopify App Store has several free apps that do exactly what WPCode does for WordPress:

| App | Free tier? |
|---|---|
| **Custom Code Editor by Shop Circle** | Yes |
| **Code Injector by GLO** | Yes |
| **Easy Code · Custom CSS, JS, HTML** | Yes |
| **Magical Apps Custom JS/CSS** | Yes |

Install one → paste our snippet into its "footer / before `</body>`" slot → save. Done. The merchant never touches Liquid.

### Option C — Proper Shopify App with Theme App Extension (long-term, what real vendors do)

Tidio, Drift, Crisp etc. all distribute via the official Shopify App Store. The flow is:

1. Build a small Shopify app (Node/Rails/Django + Shopify's CLI)
2. Inside it, ship a **Theme App Extension** with an "App embed" block
3. Submit to the Shopify App Store (1–4 week review)
4. Merchants install your app → toggle the embed ON in theme customiser → widget appears, no code paste

This also gets us:
- One-click install for thousands of merchants
- OAuth tokens so we can auto-register webhooks via Shopify Admin API (no manual webhook setup either — closes Phase 2 item 2.4 from the gap-analysis plan)
- Listing visibility / SEO via the App Store
- Per-app billing via Shopify (Shopify takes a cut, but it's frictionless)

This is **1–2 weeks of work** + review time. Most early-stage SaaS skip this until they have a few dozen Shopify merchants asking for it.
